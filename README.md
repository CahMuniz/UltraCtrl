UltraCtrl – Sistema de Vendas

UltraCtrl é um pequeno sistema de vendas desenvolvido por jovens universitários apaixonados por tecnologia e games. O projeto permite cadastrar produtos, visualizar itens disponíveis, adicionar ao carrinho e simular uma compra.

Funcionalidades:

Cadastro de produtos (nome e preço)
Exibição de lista de produtos
Inclusão de imagens dos produtos
Carrinho de compras funcional
Alteração de quantidade de itens
Remoção de produtos
Cálculo automático de total
Navegação entre páginas (Início, Produtos e Contato)

Tecnologias Utilizadas

HTML5
CSS3
JavaScript Vanilla
Manipulação do DOM
Eventos dinâmicos via JS
